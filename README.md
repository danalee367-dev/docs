# Stock Portfolio Tracker

증권사별 국내·해외 주식 보유현황과 월별 투자 성과를 Excel에서 관리하기 위한 포트폴리오 템플릿입니다.

여러 증권사에 분산된 주식 자산을 하나의 Excel 파일에서 정리하고, 계좌별·시장별 월간 성과를 비교할 수 있도록 구성했습니다.

> **중요:** 저장소에 포함된 종목, 수량, 가격, 평가금액, 수익률 및 월별 성과는 사용 방법을 보여주기 위한 임의의 샘플입니다. 실제 투자정보가 아닙니다.

## 주요 기능

### 증권사별 계좌 관리

다음 증권사의 국내·해외 주식계좌를 구분하여 관리할 수 있습니다.

- 미래에셋
- KB
- 삼성
- NH
- 키움
- 대신
- SK

`설정` 시트에서 증권사, 계좌구분, 시장구분, 통화 목록을 추가하거나 변경할 수 있습니다.

### 포트폴리오 현황

증권사와 시장별로 다음 항목을 관리합니다.

- 투자원금
- 현재 평가금액
- 평가손익
- 누적수익률
- 현재 비중
- 월 입금 및 출금
- 배당금

### 월별 계좌 성과

기본 양식은 **2026년 10월**부터 기록하도록 구성되어 있습니다.

- 월초 평가금액
- 입금 및 출금
- 배당금
- 월말 평가금액
- 월 수익금
- 월 수익률
- 전월 대비 증감
- 누적수익률

### 종목별 보유현황

개별 종목 단위로 다음 항목을 관리할 수 있습니다.

- 증권사, 시장, 계좌별칭, 통화
- 종목코드 및 종목명
- 보유수량 및 평균매입가
- 투자원금 및 현재 평가금액
- 평가손익 및 수익률
- 월초가, 월말가, 월 주가수익률

## 샘플 데이터

예제 파일에는 양식 사용법을 보여주기 위한 다음 샘플이 포함될 수 있습니다.

- 삼성전자 (`005930`) 100주
- SK하이닉스 (`000660`) 100주
- 2026년 10월 증권사별 국내·해외 계좌의 임의 성과 데이터

샘플의 가격, 보유수량, 원금, 평가금액 및 수익률은 실제 시장가격이나 실제 투자현황을 의미하지 않습니다.

## 권장 저장소 구성

```text
stock-portfolio-template/
├── README.md
├── .gitignore
├── LICENSE
├── templates/
│   └── stock_portfolio_template.xlsx
└── examples/
    └── stock_portfolio_sample.xlsx
```

- `templates/`: 실제 투자정보가 없는 빈 배포용 양식
- `examples/`: 임의 데이터가 들어 있는 사용 예시
- `private/`: 실제 투자 파일을 보관할 경우 사용하는 로컬 전용 폴더. Git에 올리지 않음

## 사용 방법

1. `templates` 폴더의 Excel 파일을 개인 작업 공간으로 복사합니다.
2. `설정` 시트에서 증권사, 계좌구분, 시장과 통화를 확인합니다.
3. `종목별 보유현황` 시트에 보유 종목을 입력합니다.
4. 매월 말 `월별 계좌 성과` 시트에 월초·월말 평가금액과 현금흐름을 기록합니다.
5. 실제 투자정보가 입력된 파일은 저장소 밖의 `private` 폴더나 접근이 제한된 저장소에 보관합니다.

## 실제 투자정보 보호

공개 저장소에는 실제 투자정보가 포함된 Excel 파일을 올리지 마세요.

업로드 전에 다음 항목을 삭제하거나 임의 값으로 교체해야 합니다.

- 실제 증권계좌번호와 실제 계좌 별칭
- 개인 이름, 이메일 또는 기타 개인정보
- 실제 보유 종목과 보유수량
- 실제 평균매입가와 현재가
- 실제 투자원금, 평가금액, 손익 및 수익률
- 실제 입금, 출금 및 배당 내역
- 숨김 시트, 숨김 행·열에 남은 데이터
- 셀 메모, 주석, 문서 속성에 포함된 개인정보
- 외부 파일 링크와 데이터 연결

### 안전한 공개 절차

1. 실제 투자 파일을 직접 수정하지 말고 공개용 복사본을 새로 만듭니다.
2. 공개용 복사본에서 실제 데이터를 모두 삭제하거나 명백한 임의 샘플로 교체합니다.
3. 숨김 시트, 숨김 행·열, 셀 메모, 주석, 이름 정의 및 외부 연결을 확인합니다.
4. 파일을 닫았다가 다시 열어 실제 정보가 남아 있지 않은지 검토합니다.
5. 공개용 파일만 `templates` 또는 `examples` 폴더에 복사합니다.
6. 커밋 전에 `git status`로 포함될 파일을 확인합니다.

> `.gitignore`는 보조 안전장치입니다. 실제 투자 파일을 한 번이라도 커밋하면 이후 삭제하더라도 Git 기록에 남을 수 있습니다. 최초 커밋 전에 공개용 파일인지 반드시 확인하세요.

## 공개 전 점검표

- [ ] 실제 계좌번호가 없다.
- [ ] 실제 투자금액과 수익률이 없다.
- [ ] 개인 식별정보가 없다.
- [ ] 숨김 시트와 숨김 행·열을 확인했다.
- [ ] 셀 메모와 주석을 확인했다.
- [ ] 외부 데이터 연결과 개인 경로를 제거했다.
- [ ] 예제 데이터가 임의 샘플임을 표시했다.
- [ ] `git status`에서 공개 대상 파일만 확인된다.

## 면책 고지

이 프로젝트는 개인 자산관리와 Excel 활용을 위한 템플릿입니다. 저장소의 데이터는 예시이며 특정 주식이나 금융상품의 매수 또는 매도를 권유하지 않습니다. 투자 판단과 결과에 대한 책임은 사용자에게 있습니다.

## 기여

Excel 수식, 데이터 구조, 대시보드 및 사용성 개선 제안은 Issue 또는 Pull Request로 제출할 수 있습니다. 기여 내용에는 실제 투자정보나 개인정보를 포함하지 마세요.
